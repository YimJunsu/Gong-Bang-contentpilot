## ① 연예인 — 공통 패턴

**화면 틀** (2·4·9·10·11 공통, 3은 검정판)
- 위 흰 판(화면 약 20%)에 제목 2줄. 1줄 검정, 2줄은 핵심어 빨강(원데이슈) 또는 인물 이름만 색(리센느 로그: 이름 초록 형광).
- 그 아래 원본 영상을 꽉 차게. 영상 맨 위에 작은 글씨 `출처: 인기가요` / `출처: m.net MAMA`, 가운데 흐린 채널 워터마크.
- 담장너형: 영상을 가운데 4:3으로, 아래 흰 칸에 그룹 이름(손글씨체).

**제목 공식** — 궁금증 + 감정, 결말을 다 말하지 않음
- 반전/관계: "리브 또 그럴줄 알았다ㅋㅋ", "내가 왜 막내야?", "빠른년생 문화가 없어져야 하는 이유"
- 빠진 것·사건: "미나미 **없는** 리센느 앵콜 라이브", "기다리던 MAMA에서 **결국** 눈물보인 리센느"
- 모음: "보기만 해도 아찔한 관객 난입 레전드 (TOP6)"
- 3번은 수식어 줄 + 노랑 강조 줄: "노래퀄 1티어 리센느 컴백 / 띵곡의 향기가 난다"

**자막 두 가지**
1. 설명 자막: 흰 글씨 작은 2줄, 상황을 이어 주는 말. "5년 안에 서겠다던 MAMA를 1년도 안 돼서 서게 됨", "업로드 당시 26년 5월 / 큰 무대에서 만나자 약속했던 두 사람"
2. 반응 자막: 검정 반투명 상자 안 팬 말투. "와...노래 진짜 높다...ㅈㄴ 높네진짜...", "미나미 없으면 안될 듯ㅋ"(첫 장면은 빨강 글씨 검정 띠로 크게)
- 예능 클립(2·4)은 출연자 대사를 그대로 받아 적고 핵심어만 노랑, 속말은 `(학교를 빨리 갔어요..)` 작은 괄호, 놀람에 빨간 `!`·물음표 말풍선 스티커.

**구성**
- 10번: 예전 인터뷰(약속) → 지금 시상식 무대 → 눈물. **출처 2~3개를 이야기 순서로 섞음**.
- 11번: TOP6 모음. 장면마다 위에 인물 이름(흰 굵게) + 노란 한 줄 평("멀리서 지켜보다 글러가서 귀엽단 반응ㅋㅋㅋ"), 위에 초록 띠 부제("진짜 왜 그러는 거야 정신 좀 차려...").
- 소리는 원본 그대로(라이브·예능 대사가 핵심). 길이 16~69초, 대부분 30~60초.
- 첫 1초에 제일 센 장면 + 그 장면 반응 자막.

## ② 해외 퍼오기 — 공통 패턴 (해치웠나 4편 = 1천만~3천만 조회)

**화면 틀**
- 검정 바탕. 위에 굵은 제목 2줄(아주 두꺼운 고딕), 한 줄은 노랑·다른 줄은 흰색(또는 빨강+노랑).
- 가운데 영상을 1:1~4:5로 잘라 넣고, 바로 아래 회색 `©원작자이름`(예: ©MillennialCarpenter, AGT 로고).
- 자막은 영상 가운데쯤 흰 글씨 + 검정 테두리, 핵심어는 노랑. 한 번에 2~6단어.

**가장 큰 차이: 한국어 내레이션**
- 한국어 목소리 해설 형식으로 보인다(**자동 자막 앞부분 300자만 확인, 소리는 안 들어 봄** — 끝까지 해설인지, 배경음악·원본 소리 크기는 미확인. 2026-11-25 바로잡음).
- 말투: 다큐 해설체 "~인데요", "~죠", "~됩니다". 예)
  - "1m가 넘는 팬에 고기가 끝도 없이 올라갑니다. 11명 대가족을 둔 미국 엄마의 식사 준비 모습인데요."
  - "현장에 신입이 두 명이 들어왔는데 똑같은 일을 시켜도 이렇게 다릅니다. 첫째는… 반면, 둘째는"
  - "그리고 잠시 후 … 드론에 엄청난 장면이 찍히게 되는데" → 말 끊고 음악 + 결정적 장면
- 첫 문장 = 가장 신기한 사실을 바로 던짐(설명보다 그림 먼저).
- 결정적 순간 직전에 "그리고 잠시 후", "알고 보니", "반면 둘째는"으로 끊고 원본 소리를 살림.
- 노래 무대(8번)는 해설로 상황만 깔고 노래 부분은 원본 소리 + 가사 번역 한 줄.

**제목 공식**: [누가 놀랐나/어떤 평가] + [누구의 무엇]
- "현장 고인물 감탄시킨 신입 막내의 일머리", "마이클 잭슨의 환생 같다는 소년의 무대", "초자연적인 현상을 눈앞에서 목격한 서퍼들", "미국 상류층 엄마의 11명 대가족 식사 준비"
- ㅋㅋ·반말 없이 담백. 이상함·대단함을 남의 입("감탄시킨", "같다는")으로.

**1번(앵무새)**: 흰 바탕 + 평범한 글씨 제목 + 영상 + 아래 댓글 카드(실제 유튜브 댓글 캡처 모양). 해설 없이 짧은 설명 자막. 길이 20초.

길이 19~44초. 한 영상 한 원본(섞지 않음).

## 지금 우리 것과 차이

| | 지금 | 레퍼런스 |
|---|---|---|
| ① 화면 | 흰 띠 + 코랄/보라 제목(stick) | 비슷. `출처: 방송명` 줄 없음 |
| ① 자막 | 시청자 반응 한 종류 | 설명 자막 + 팬 반응 상자 두 종류, 예능은 대사 받아쓰기 |
| ① 원본 | 최대 2개, 하이라이트 위주 | 2~3개를 **이야기 순서**(과거 약속→지금→감정)로, 또는 TOP N 모음 |
| ② 화면 | 검정 + 노랑 도장(stamp) | 검정 + 노랑/흰 제목 2줄, `©원작자` 영상 아래 |
| ② 말 | 반응 말풍선 + 번역 자막, 목소리 없음 | **한국어 해설 목소리**가 전체를 끌고 감, 원본 소리 낮춤 + 음악 |
| ② 말투 | 친구 반응("오 지린다;") | 다큐 해설체("~인데요", "그리고 잠시 후") |

## 반영 제안 (확인 후 작업)

1. **② 해설 모드**: AI가 해설 대본(첫 문장 = 제일 신기한 사실, "~인데요/~죠", 결정적 순간 직전 끊기) → 기존 TTS(`video.mjs`, Edge 무료 목소리)로 읽기 → 원본 소리 20% + 해설, 결정적 구간은 원본 소리 100%. 자막 = 해설 문장. 화면은 새 꾸미기 `story`(검정, 노랑/흰 제목 2줄, `©원작자`). 친구 반응 말투(stamp)는 선택지로 남김.
2. **① 이슈 모드**: 화제 하나에 출처 2~3개(예능/인터뷰/무대)를 이야기 순서로, 설명 자막 + 팬 반응 상자 두 종류, `출처: 프로그램명` 줄. 예능이면 대사 받아쓰기 + 핵심어 노랑.
3. **① TOP N 모음**: "레전드 TOPn" 형식 — 장면마다 인물 이름 + 한 줄 평.
4. 하지 않음: 실제 사람 댓글처럼 보이는 가짜 댓글 카드(1번 방식). 꾸며 낸 댓글을 진짜처럼 보이게 하는 것이라 뺀다.
