# 글 자동화 설계

작성 2026-10-18. 기준: 선배 블로그 이슈 글 3편(안원잘부 다이어리 2027 / 리센느 메이 / 고윤정 서울여대)을 SmartEditor 구조로 분석한 결과.

## 목표

정해진 시간마다 **핫 키워드·숏텐츠에서 이슈 주제를 골라 → 자료·공식 이미지를 모으고 → 글을 쓰고 → 임시저장**까지 자동으로 한다. **발행은 사람이 한다**(사용자 결정, 2026-10-18). 네이버 운영정책상 자동 대량 발행은 제재·저품질 위험이 있다.

## 레퍼런스 글에서 가져올 것

| 항목 | 레퍼런스 | 우리 규칙(반영 위치) |
|---|---|---|
| 분량 | 공백 제외 1,270~1,630자 | A 1,500~2,200 그대로 |
| 소제목 | 3~5개, `① 가격과 종류` | 기존 H2 규칙 그대로(형식 구분 안 함) |
| 이미지 | 5~9장, 전부 실제 이미지 + 캡션 `사진: ○○` | 공식 배포 + 공식 영상 장면, 캡션 출처 한 줄 (`공통-작성기준.md` 실제 이미지) |
| 썸네일 | 공식 이미지 | **오덕이 필수** — 공식 이미지를 참고로 그 상황을 한 장면으로 재현 + 큰 글자 (지식 파일 썸네일 규칙 `공식 이미지가 있는 글`) |
| 강조 | 결론 한 줄 = 음영 #fff593 + 굵게 + 큰 글씨, 가격·날짜 = 빨강 #ff0010 굵게 | `<mark>` 15px, `<strong class="num">` (전 카테고리) |
| 바뀌는 숫자 | "10월 18일 오후 2시 20분 무렵 기준 453만 회" | 확인 시각 필수 |
| 링크 | 공식몰 링크 카드 1개, 내 다른 이슈 글 1개 | 본문 링크 1개 + 내부 링크 1개 (카드·영상 삽입은 아래 4단계) |
| 인물 사진 | 본인 인스타그램 게시물 | **쓰지 않음** — 공식 배포·공식 영상 장면만, 내용과 정확히 일치 |

## 흐름

```
[스케줄러] 설정한 시간(예: 하루 2~3회)
  → ① 주제 고르기   핫 키워드(어제 기준) + 숏텐츠(지금) → AI가 후보 점수
                     - 제외: 사생활·루머·사건사고, 이미 쓴 글과 비슷한 주제(similarPost), 공식 자료가 없을 주제
                     - 계정별(기본 계정 폴더) 하루 상한 안에서 1편씩
  → ② 공식 자료 찾기 AI가 웹 검색으로 공식몰·뉴스룸·공식 유튜브·보도 주소 3~5개 확정
  → ③ 이미지 모으기  공식 페이지 이미지 후보(naver.scrape withImages) + 공식 영상 썸네일
                     + (선택) 공식 영상 장면 캡처 — 아래 '영상 장면' 참고
  → ④ 글 쓰기        블로그 규칙 + 사진 없음 → 공식 사진·캡처 우선, 참고 링크 = ②의 주소들
  → ⑤ 검증           validate-post.ps1 통과까지 AI가 고침(지금과 같음)
  → ⑥ 임시저장       기본 계정(또는 지정 계정)으로
  → ⑦ 알림           Windows 알림 + 작업 로그. 사람은 미리보기로 확인 → 네이버에서 발행
```

## 정해야 할 것 / 위험

### 영상 장면 캡처

레퍼런스는 공식 영상 장면을 4~6장 쓴다. 방법:

| 방법 | 장점 | 위험·한계 |
|---|---|---|
| A. 사람이 캡처해 첨부 | 안전, 정확 | 자동화가 안 됨 |
| B. 도구가 브라우저로 공식 영상을 재생해 지정 시점 화면만 캡처(영상 파일은 받지 않음) | 자동, 정확한 시점 | 유튜브 약관의 '자동화된 접근' 회색지대, 광고·로그인 팝업에 막힐 수 있음 |
| C. 공식 썸네일만 | 안전, 간단 | 장면이 1장뿐 |

권장: **C를 기본으로 하고 B를 설정에서 켤 수 있게**. 시점은 영상 설명·댓글의 타임스탬프(`32:54`)나 AI가 고른 장면으로 정하고, 캡처마다 시점을 검증 메모에 남긴다.

### 링크 카드·유튜브 삽입

`vendor/html.js`는 글자·표·이미지·소제목·인용구만 옮긴다. 링크 카드(oglink)·영상 삽입(oembed)은 SmartEditor 컴포넌트를 새로 만들어야 한다 → 4단계. 그전에는 본문 링크 텍스트로 둔다.

### 품질·계정 보호

- 하루 상한(기본 2편, 최대 5편), 같은 날 같은 주제 묶음 1편, 임시저장 사이 간격 10분 이상
- 자동 생성 글은 '자동' 표시를 남겨 글 목록에서 걸러 볼 수 있게(meta.json `auto: true`)
- 실패하면 다음 주제로 넘어가고, 연속 3번 실패하면 그날 멈추고 알림
