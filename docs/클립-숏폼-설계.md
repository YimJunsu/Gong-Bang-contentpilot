# 클립 숏폼 설계 (숏폼 만들기 2)

작성 2026-11-13. 레퍼런스: 유튜브 `@리즈시절천개모으기`, `@30초인물소개` 쇼츠 탭 + 다른 도구의 '편 목록 → 자동 제작 → 보고 올리기' 화면(캡처 3).

## 목표

**인물·화제(예: "미야오 안나", "지수 대기실 인형 같은 순간")만 넣으면** → 유튜브에서 원본 영상을 찾아 → 볼 만한 구간을 잘라 → 위에 훅 제목, 아래에 자막을 얹은 세로 영상(20~40초)으로 만든다. 업로드는 사람이 한다(블로그 임시저장과 같은 원칙).

기존 숏폼 만들기와의 차이:

| | 숏폼 만들기(지금) | 클립 숏폼(새로) |
|---|---|---|
| 화면 | 내 사진·AI 이미지 + 효과 | **유튜브 원본 영상 구간** |
| 소리 | TTS 낭독(감정 톤) | **원본 소리**(무대 음악·말소리). TTS는 선택 |
| 글자 | 큰 제목 + 낭독 자막 | 검은 띠 위 2줄 훅 제목 + 아래 해설 자막(큰 줄 + 작은 줄) + `출처: 채널` |
| 입력 | 주제·자료 | 인물·화제 (+ 영상 주소 직접 지정 가능) |

## 레퍼런스에서 가져올 것

| 항목 | 레퍼런스 | 우리 규칙 |
|---|---|---|
| 상단 | 검은 띠, 흰 줄 + 강조 줄(분홍 배경·노란 글자·밑줄) 2줄 | `title: ["흰 줄", "*강조* 줄"]` — 지금 대본 형식 그대로, 레이아웃만 새로 |
| 훅 문구 | "역변해서 속상하다는 원조 리틀 제니", "현역 아이돌인데 망사 가터벨트 맞아요..?" | 반전·궁금증·비교형 훅. **외모 품평·성적 표현·루머는 금지**(아래 위험 참고) |
| 화면 | 직캠·방송 장면을 세로로 꽉 채움 | 원본을 9:16로 자르되 인물 위치(가로%)를 AI가 지정 |
| 자막 | 아래쪽 흰 큰 줄 + 노란 작은 줄(드립·리액션) | 구간마다 `caption` + `sub` |
| 출처 | 화면 위 작게 `출처: @채널`, 설명란에 원본 주소 | 영상 안 출처 표시 필수 + 설명란 원본 주소 자동 |
| 길이 | 20~40초, 컷 3~6개 | 구간 3~6개, 컷당 3~8초 |

## 흐름

```
① 입력      인물·화제 (+ 메모, + 영상 주소 0~3개 직접 지정)
② 영상 찾기  yt-dlp "ytsearch20:<인물> 직캠|무대|예능" 목록만(다운로드 X)
             → AI가 2~4개 고름. 공식 채널(방송사·소속사·M2·1theK 등) 우선
③ 구간 찾기  고른 영상을 저화질로 받아 2초 간격 장면 모음 그림(ffmpeg tile) 생성
             + 있으면 '가장 많이 다시 본 구간'(yt-dlp heatmap) + 자막
             → AI가 그림을 보고 구간 3~6개와 인물 위치를 고름
④ 클립 받기  yt-dlp --download-sections 로 고른 구간만 1080p로 받음
⑤ 대본       AI: 훅 제목 2줄, 구간별 자막(큰 줄·작은 줄), 설명(출처 주소 포함), 해시태그, 추천 사운드
⑥ 렌더       stage.html 'clip' 레이아웃 → 원본 소리 그대로(구간 사이 짧은 페이드)
⑦ 점검 그림  완성본에서 1초 간격 장면 모음 그림 → 화면에서 한눈에 확인
⑧ 보고 올리기 편 목록에 '올릴 차례'. 사람이 업로드 후 유튜브 주소를 넣으면 '올림'
```

### 확인된 것 (2026-11-13, 이 PC)

- `yt-dlp 2026.08.19` 설치돼 있음. `ytsearch5:미야오 안나 직캠` → MBCkpop·M2·SBSKPOP ZOOM(공식) + 개인 업로더가 섞여 나옴. 캡처 3의 설명란 주소(`youtu.be/dblLC…`)가 M2 공식 직캠 — 레퍼런스도 공식 직캠을 씀.
- 최대 2160p 포맷 있음. 자동 자막 목록 있음.
- **heatmap(많이 다시 본 구간)은 시험한 영상에서 비어 있었음** → 보조 신호로만 쓰고, 기본은 장면 모음 그림을 AI가 보고 고른다.
- 구현·실행 확인(2026-11-13, 선택지 (가)로 구현): 자동 찾기(인증 채널만) → codex가 KBS Kpop 얼빡직캠 2개 선택 → 받기(영상당 약 18초, 1080p 100MB 안팎) → 장면 모음 그림 → codex 구간·자막 → 렌더 21초 영상 **약 2분 13초**. 주소 직접 넣기 + 원본 소리 끄기(무음 확인), 다시 생성(같은 폴더) 확인.
- 실제 구현은 설계와 조금 다르다: 구간만 받지 않고 **원본을 통째로 받아** ffmpeg로 자른다(장면 모음 그림도 같은 파일에서, 다시 렌더할 때 다시 받지 않음). 글자판은 stage.html 대신 `assets/clip.html`을 장면마다 한 번 찍어 얹는다(프레임 캡처보다 빠름, 렌더 5~10초).
- 원본은 `src/`에 남는다(편당 100~250MB). 다 올린 편은 폴더째 지워도 된다.

## 만들 것 (기존 코드 재사용)

| 위치 | 내용 |
|---|---|
| `clip.mjs` (새) | `searchVideos(q)`, `contactSheet(file)`, `downloadSection(id, from, to)` — yt-dlp·ffmpeg 호출만. `clipPrompt()`, `validateClip()` (reel.mjs처럼) + `clip.check.mjs` |
| `server.mjs` | `jobTypes.clip` (②~⑦ 순서대로, 각 단계 로그). 폴더는 지금 숏폼과 같은 `shorts/` 아래 `YYYYMMDD-인물-xxxx`. `POST /api/shorts/uploaded`(유튜브 주소 저장) |
| `assets/stage.html` | `layout: 'clip'` 하나 추가: 검은 상단 띠 + 제목 2줄, 영상 영역, 아래 자막 2줄, 출처 글자. 기존 `video` 장면 재생·자막 코드 재사용 |
| `video.mjs` | `renderShort`에 `script.audio === 'source'`면 TTS 대신 클립 원본 소리를 쓰는 분기 |
| `app/page.jsx` | 메뉴 '만들기'에 **클립 숏폼**. 왼쪽 편 목록(할 일/전체, 상태 칩), 오른쪽 단계 표시(1 주제 → 2 자동 제작 → 3 보고 올리기) + 영상 미리보기 + 제목·설명 복사 + 유튜브 주소 입력 — 캡처 3 구조 |
| `script.json` | 지금 형식 + `layout:"clip"`, `audio:"source"`, `sources:[{url, channel, title}]`, 장면마다 `media`(클립), `focus:[x%,50]`, `lines:[{text, sub}]` |

새 라이브러리는 없음. yt-dlp는 외부 프로그램(이미 설치) — 없으면 시작 전에 막고 설치 안내(`winget install yt-dlp`).

## 정해야 할 것 / 위험

1. **저작권 (가장 큼).** 남의 영상을 받아 재편집해 올리는 건 공식 채널 영상이라도 허락받은 게 아니다. 유튜브 저작권 신고(Content ID 소유권 주장·경고 3회 시 채널 삭제), '재사용 콘텐츠'로 수익 창출 거절 가능성이 있다. 또 지금 블로그 쪽 결정은 "영상 파일은 받지 않는다"(장면 캡처만)인데, 이 기능은 그걸 뒤집는다. 선택지:
   - (가) **공식 채널만 + 짧은 구간 + 출처 표시 + 해설 자막으로 변형** — 기본값 제안. 위험은 줄지만 없어지지 않는다.
   - (나) 사용자가 직접 넣은 영상 주소만 (자동 찾기 없음)
   - (다) 제한 없음 — 권하지 않음
2. **유튜브 이용약관상 다운로드 금지.** yt-dlp 사용 자체가 약관 위반 소지. 지인에게 공유하는 도구라면 더 조심.
3. **인물 다루는 방식.** 레퍼런스 2(`@30초인물소개`)의 "가터벨트", "비키니 사진", "요염" 같은 훅은 성적 대상화로 신고·연령 제한·채널 제재 대상이 되기 쉽다. 글 자동화와 같이 사생활·루머·외모 비하·성적 표현은 프롬프트에서 금지 제안.
4. 소리: 원본 음악이 저작권 신고의 주된 원인. 옵션으로 '원본 소리 끄고 추천 사운드는 업로드 때 유튜브에서 고르기'(캡처 3의 `[추천 사운드]`가 이 방식).
5. 자동 업로드는 안 한다(YouTube Data API OAuth 필요 + 실수 위험). 나중에 원하면 별도.

## 단계

1. 수동판: 영상 주소 + 구간을 사람이 넣으면 ④~⑦만 (렌더 레이아웃·원본 소리 검증)
2. 자동 찾기: ②③ (검색 + 장면 모음 그림으로 AI 구간 선택)
3. 편 목록·보고 올리기 화면, 하루 N편 자동(스케줄러는 숏텐츠 것 재사용)
