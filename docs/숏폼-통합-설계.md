# 숏폼 통합 설계 (숏폼 메뉴 하나 + 탭 4개 + 쇼츠 자동화)

작성 2026-11-15. 사용자 결정으로 확정.

## 결정 사항

- 만들기의 **숏폼 만들기·릴스·쇼츠 만들기·클립 숏폼**을 **"숏폼" 메뉴 하나**로 합치고 탭 4개로 나눈다.
- 탭 ② 해외 재밌는 영상: **원작자(처음 올린 크리에이터·방송사) 채널 영상만** 자동으로 찾는다. 출처 표시 필수, 짧은 구간, 한국어 해설 자막으로 변형(클립 숏폼과 같은 기준).
- GIPHY 등 GIF 사이트는 쓰지 않는다(비상업 용도 조건 + GIF 원본 권리). 오덕이 스티커도 쓰지 않는다.
- 글꼴: 눈누에서 확인한 **상업 이용·영상 사용·파일 재배포 가능** 글꼴만 저장소에 넣는다(라이선스 문서 함께).
- 쇼츠 자동화: 업로드는 사람이 한다. **YouTube API 키는 선택**(있으면 공식 인기 차트, 없으면 yt-dlp 검색).

## 1. 화면

| 탭 | 넣는 것 | 만드는 방식 | 기존 코드 | 기본 길이 |
|---|---|---|---|---|
| ① 연예인 핫 | 인물·화제(+영상 주소) | 공식 영상 구간 + 훅 제목 + 자막, 원본 소리 | `clip.mjs` (job `clip`) | 20~35초 |
| ② 해외 재밌는 영상 | 분야·키워드(+영상 주소) | 원작자 채널 영상 구간 + 한국어 훅 제목 + 상황 자막 | `clip.mjs` 재활용(검색어·자막 지시만 다름, `concept: "viral"`) | 15~30초 |
| ③ 주제·컨셉 | 주제 + 컨셉(정보·이야기) | AI 이미지 + 감정 낭독 | `reel.mjs` (job `reel`) | 40~60초 |
| ④ 내 사진·자료 | 주제 + 사진·영상·PDF | 내 자료 + 감정 낭독 | `video.mjs` (job `shorts`) | 40~60초 |

- 길이는 탭마다 짧게/보통/길게로 고른다(기본값은 위 표).
- 탭마다 **글꼴 + 제목 스타일**을 고르고, 탭별 기본값이 있다. 고른 값은 브라우저에 기억(`useSticky`).
- 아래 **만든 숏폼 목록**은 하나로 합치고 탭(종류)으로 거른다. 편 목록·보고 올리기(올렸어요 표시)는 이 목록으로 옮긴다.

## 2. 글꼴·스타일

- 우리 글꼴 세트(눈누 확인 2026-11-15): G마켓 산스, 카페24 써라운드, 마루 부리, 프리젠테이션, 프리텐다드(이미 있음) + 기존 검은고딕·도현·주아(OFL). 각 글꼴의 라이선스 문서를 `assets/fonts/licenses/`에 둔다.
- 여기어때 잘난체는 넣지 않는다(눈누 요약과 원문이 달라 재배포 불확실).
- `title-styles.mjs`를 **글꼴 × 색 조합**으로 나눈다. 클립(①②, `assets/clip.html`)과 낭독형(③④, `assets/stage.html`)이 같은 목록을 쓴다.
- ② 기본 스타일(레퍼런스 캡처): 검은 상단 띠, 첫 줄 흰 박스 안 검은 글자, 둘째 줄 형광 초록, 가운데 흰 자막(검은 외곽선) + 노랑 강조.

## 3. 쇼츠 자동화 (자동화 메뉴)

- 분야 고르기(엔터·음악·코미디·게임·스포츠·동물 등) + **지금 만들기** 버튼.
- 흐름: 인기 영상 찾기(API 키 있으면 `videos.list chart=mostPopular regionCode=KR videoCategoryId`, 없으면 yt-dlp "이번 주 업로드·조회수 순" 검색) → 원작자 채널만 → 이미 만든 영상 제외 → 분야당 상위 1~3개를 ①/② 방식으로 생성 → 숏폼 목록에 '올릴 차례'.
- 하루 상한·시간 예약은 글 자동화와 함께 나중에.

## 4. 안전장치

- 자동 찾기는 원작자·공식 채널만, 출처를 영상 안과 설명란에 표시.
- 짧은 구간 + 해설 자막으로 변형. 외모 품평·성적 표현·루머 금지.
- 원본 소리 끄기 옵션(음악 신고 대비, 이미 있음).

## 5. 순서

1. 메뉴 합치기 + 탭 + 글꼴 세트·스타일 통합 + 길이 선택
2. ② 해외 재밌는 영상 탭
3. 쇼츠 자동화
