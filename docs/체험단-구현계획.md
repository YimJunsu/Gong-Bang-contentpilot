# 체험단 정보 조회 구현 계획

사용자가 제공한 `체험단 정보 조회 메뉴 설계서.md`의 기능을 현재 로컬 앱에 통합한다. 문서의 Spring/MySQL/AWS 가정은 적용하지 않는다.

## 확정한 구조

- Next.js 16 / React 19 / Node.js ESM / 기존 CSS와 SUIT를 유지한다. 새 의존성은 추가하지 않는다.
- `campaigns.mjs`: 사이트 등록, HTML 목록 어댑터, 표준화, JSON 저장소, 조회/필터, 즐겨찾기, 순차 수집과 상태 관리.
- `data/campaigns.json`: 공고, PC 공용 즐겨찾기, 사이트 상태, 최근 수집 이력. 임시 파일을 쓴 뒤 교체한다.
- `server.mjs`: 기존 보안 경계 안에서 API와 3시간 주기(한국 시간 06~24시) 수집을 연결한다. 화면 조회는 외부 사이트를 호출하지 않는다.
- `app/campaigns.jsx`: 기존 공통 Head/Action을 사용한다. 검색, 다중 지역/카테고리/출처, 유형, 마감, 포인트, 즐겨찾기, 마감 포함, 정렬, 카드/표, 페이지네이션/더 보기, 수집 상태를 제공한다.
- `/campaigns` 진입을 지원하고 필터는 URL, 보기 선택은 localStorage에 보존한다. 기존 메뉴의 탭 방식도 유지한다.

각 수집 실행 시 robots를 다시 확인한다. 403/429는 해당 사이트를 즉시 중단한다. 같은 사이트의 요청 간격은 2~5초, 타임아웃은 15초, 재시도는 2회, 실행당 최대 30페이지다. 급감/실패 시 기존 공고를 보존한다. 부분 수집이나 페이지 상한 도달을 공고 삭제 근거로 사용하지 않는다.

- [x] 수집/저장/검색과 서버 API를 구현하고 자체 검사를 통과시킨다.
- [x] 화면과 메뉴, URL 복원, 모바일 필터, 사용 안내를 구현한다.
- [x] 실제 공개 목록으로 수집을 검증하고 허용/제한 사이트를 문서화한다.
- [x] 기존 `npm run check`, Next 빌드, API와 데스크톱/모바일 화면을 확인한다.

2026-11-04 실제 수집: 디너의여왕 900건, 강남맛집 840건. 양쪽 모두 30페이지 상한 내 공개 블로그 목록 수집에 성공했다. 실제 로컬 서버에서 검색/필터 주소 복원, 즐겨찾기 저장 및 새로고침 후 유지, 카드·표 전환, 표 페이지 이동, 원본 302 이동, 미등록 공고 404, Host 및 쓰기 헤더 경계, 390px 모바일 필터·뒤로가기·가로 넘침을 확인했다. 검사 중 변경한 즐겨찾기는 되돌렸다.

외부 알림 계정은 추가하지 않는다. 기존 Windows 알림을 이용해 연속 실패를 알린다. 회원 기능 없이 PC 공용 즐겨찾기를 제공한다. 크롤링 금지 사이트를 우회하거나 원본 상세 본문·이미지를 저장하지 않는다.
